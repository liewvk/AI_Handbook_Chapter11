# AI Handbook — Chapter 11

A collection of Python examples for Chapter 11 of the AI Handbook. The examples introduce NumPy arrays and pandas DataFrames, plus common data-preparation operations used for machine-learning workflows.

## Examples

| Example | Topic |
|---|---|
| `example11.2.py` | NumPy arrays, shapes, dimensions, and arithmetic |
| `example11.3.py` | NumPy matrices and indexing |
| `example11.4.py` | Mean and standard deviation |
| `example11.5.py` | Feature scaling with NumPy broadcasting |
| `example11.6.py` | Creating and inspecting pandas DataFrames |
| `example11.7.py` | Filtering rows and selecting columns |
| `example11.8.py` | Identifying and filling missing values |
| `example11.9.py` | Numeric conversion, duplicates, and invalid values |
| `example11.10.py` | Creating derived columns and aggregations |
| `example11.11.py` | One-hot encoding categorical data |
| `example11.12.py` | Z-score standardization |
| `example11.13.py` | Writing and loading CSV data |
| `example11.14.py` | Preparing features and targets with pandas |

`clean_students.csv` is generated by `example11.13.py` and stores a small hours-and-scores dataset.

## Requirements

- Python 3
- NumPy
- pandas

Install the packages with:

```bash
pip install numpy pandas
```

## Running the examples

Run an example from the repository root:

```bash
python example11.2.py
```

For example 11.13, run it from the repository root so `clean_students.csv` is read from the correct location:

```bash
python example11.13.py
```

You can run the remaining examples by replacing the filename in the command.

## Development

The repository also includes Visual Studio project files:

- `AI_Handbook_Chapter11.pyproj` — Python project configuration
- `AI_Handbook_Chapter11.slnx` — Visual Studio solution

The project is configured to start with `example11.14.py`.
